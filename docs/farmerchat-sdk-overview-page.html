What you get

Features

One-call journey

Splash → language → name → home → chat, fully wired. You launch; the SDK runs the flow.

Auth, handled

Phone + OTP built in with token refresh — or switch to host-token mode and pass your own user.

Themed to your app

Override colors, fonts, corner radii, and the logo from one config. Every screen recolors — no per-screen work.

Import by coordinate

Maven for Android, SPM/CocoaPods for iOS, npm for React Native and Web. Standard dependency, standard install.

Rich chat

Text, voice-to-text, and photo questions; listen (TTS); share & save. Answers arrive as a single response, revealed with a typewriter-style animation (Android Compose today — not live streaming).

Speaks their language

Server-driven labels with English fallback, plus host string overrides and a forced-locale option.

Fits any layout

Full-screen journey, a floating button, chat-only mode, or embed it inline inside your own screen.

Your analytics

Every event reaches you through one listener. No third-party trackers bundled in the SDK.

Add it in minutes

Integration — Android

The same shape applies on every platform: add the dependency, initialize once with a theme, then launch.

// settings.gradle.kts
repositories { mavenCentral() }

// app/build.gradle.kts
implementation("org.digitalgreen.farmerchat:farmerchat-android-compose:1.0.0")

// Application.onCreate — initialize once, themed to your app
FarmerChat.initialize(this,
  FarmerChatConfig.builder(FarmerChatEnvironment.PROD)
    .theme(FarmerChatTheme.builder()
      .brandPrimary(0xFF1565C0.toInt())   // your brand color
      .fontFamily(R.font.host_sans)     // your font
      .logo(R.drawable.host_logo)       // your mark
      .build())
    .build())

// anywhere in your app
FarmerChat.launch(context)
