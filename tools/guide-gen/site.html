FarmerChat SDK Integration

FarmerChat is an AI advisory assistant for farmers — onboarding, a daily advice feed, and a chat that answers questions by voice, photo or text in the farmer's own language. This SDK embeds that whole journey inside a partner application.

The same public surface ships on seven flavours across four platforms. Every one is documented in full on this page, with the identical section list, so an integration written against one translates directly to the others.

What farmers get

FarmerChat is Digital Green's AI farming advisor. The SDK puts its chat inside your app or website, so your farmers can ask a question and get practical advice without leaving your product.

Ask by voice, photo or text

Farmers speak a question, snap a photo of a sick plant, or type. No forms, no menus.

Answers in their own language

Every word on screen comes from FarmerChat in the language the farmer picks.

Follow-up questions

Each answer suggests the next useful question, so farmers keep learning with one tap.

Listen and share

Answers can be read aloud for farmers who prefer listening, and shared with others.

On a plain HTML page

The FarmerChat widget is one script. Paste these two tags before </body> and a chat button appears in the corner of the page; tapping it opens FarmerChat in a panel (full screen on phones).

To open chat from your own button, call FarmerChatWidget.open(), or FarmerChatWidget.open('When should I harvest paddy?') to ask straight away.

Before you go live

FarmerChat's servers do not yet accept the SDK's requests from other websites: their browser rules (CORS) block the headers the SDK sends. Until the FarmerChat team allows them, point the widget at a small proxy, as the live demo does with customBaseUrl.

The script URL below is the demo's copy. For production, host farmerchat-widget.iife.js and its illustrations/ folder on your own site or CDN.

index.html
<!-- 1. Settings (all optional) -->
<script>
  window.farmerChatWidgetSettings = {
    config: {
      environment: 'demo',
      enableAgenticChat: true,   // streaming answers
      // customBaseUrl: 'https://your-proxy.example/',
    },
    launcherLabel: 'Ask FarmerChat',
  };
</script>

<!-- 2. The widget -->
<script src="https://farmerchat-sdk-suite.vercel.app/dist/farmerchat-widget.iife.js"></script>

Questions

Good to know

What will farmers see?

By default, only the chat: they open it and ask. Language is a button in the chat bar; turn on showHistory to add past chats there too. If you want the full FarmerChat journey — language and name onboarding, a Home feed of daily advice, a menu — set mode to FULL_JOURNEY.

Do answers type out as they arrive?

Yes, with enableAgenticChat on: progress steps show first, then the answer streams in word by word.

Which platforms and versions?

Android (Jetpack Compose and XML Views), iOS (SwiftUI, UIKit and Objective-C), React Native, and the web (React or a plain HTML page). Every platform is version {{VERSION}}.

Can we install it from Maven, CocoaPods or npm today?

Not yet. The packages are not published to public repositories, so for now you build from source and use them locally. Each platform's install section below shows how.
