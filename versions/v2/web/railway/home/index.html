Developer guide

Two ways to put FarmerChat on the web

FarmerChat answers farmers' questions by photo, voice or text in their own language. Run it as the whole page of your web app, or add it to any website as a chat button. Try both below, then copy the code that matches your site.

Web app · npm + React

FarmerChat as your whole app

The complete FarmerChat experience fills the page, the same journey as the mobile app.

  • Language choice, Home feed with weather and crop tips, chat, history and settings
  • Mounts inside your own React app and follows your theme
npm install @digitalgreenorg/farmerchat-web react react-dom

import { FarmerChat } from '@digitalgreenorg/farmerchat-web';

export function App() {
  return <FarmerChat inline config={{
    environment: 'prod',
    mode: 'FULL_JOURNEY',
  }} />;
}

Website widget · one script tag

A chat button on any website

A button in the corner of your site opens FarmerChat in a panel. Visitors start chatting straight away.

  • Works on any page: no React and no build step
  • Becomes full screen on phones; closing keeps the conversation
<script>
  window.farmerChatWidgetSettings = {
    config: { environment: 'prod' },
    launcherLabel: 'Ask FarmerChat',
  };
</script>
